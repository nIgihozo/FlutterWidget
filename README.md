# AppBar Widget 

An `AppBar`: is a top toolbar used in Flutter to display app branding, page titles, navigation, and quick action buttons.

In this project we provided a simple real-world profile screen demonstrating the Flutter `AppBar` widget.

## How to Run
1. Clone this repository.
2. Run `flutter run` in your terminal on an emulator or connected device.

## Demonstrated Attributes
- **title:** Sets the heading text displayed in the bar.
- **backgroundColor:** Customizes the background color of the top bar.
- **centerTitle:** Centers the title text horizontally across platforms.
